I developed a basic Python chatbot that operates in the terminal and responds to questions about the iPhone 18 Pro, Pro Max, and Duo, much like the tools on many websites that handle queries and supply relevant details.  

It relies on dictionaries and keyword matching to provide information such as price, storage, colors, display, and camera.  

This modest project helps practice Python and understand how chatbots function. Feedback is welcome!
